# Garden Romance — foto contoh

Tema visual contoh: ivory, sage, antique gold, bunga putih, dan fotografi pernikahan di taman. Foto merupakan placeholder yang dapat diganti melalui dashboard.

Foto baru yang dikurasi dari halaman Unsplash berlisensi gratis:

- Alexander Mass, potret pria: https://unsplash.com/photos/groom-in-light-blue-suit-looking-out-window-5GtM29oggKU
- Tim Bish, potret wanita: https://unsplash.com/photos/a-bride-holding-a-bouquet-of-flowers-in-her-hands-ApMfo_r7lME

- Nicole Corbin, rangkaian bunga: https://unsplash.com/photos/white-flower-arrangement-i4NqeIHNbTI
- Rizky Motion, pasangan pengantin Indonesia: https://unsplash.com/photos/a-bride-and-groom-posing-for-a-wedding-portrait-2BrCSZcg0o4

Foto Unsplash yang sudah ada pada aplikasi dipakai kembali untuk variasi hero, cerita, dan galeri: `photo-1515934751635-c81c6bc9a2d8`, `photo-1519741497674-611481863552`, `photo-1520854221256-17451cc331bf`, `photo-1511285560929-80b456fea0bc`, dan `photo-1519225421980-715cb0215aed`.

Ornamen SVG daun/bunga dan bingkai oval dibuat untuk proyek ini. File terdapat pada `assets/images/garden-*.svg`.

Studio Desain → Posisi foto dan animasi → **Lapisan warna di atas background** mengatur keterbacaan foto latar. Nilai 0 menampilkan gambar asli; nilai yang lebih besar menambahkan warna latar pilihan. Default 0 mempertahankan desain sebelumnya.
